## Как запустить (Windows)

Все команды — в папке `Documents\antifraud\antifraud_week3` (в Проводнике: клик по адресной строке → `cmd` → Enter).

Один раз:

```
..\.venv\Scripts\python.exe -m pip install fastapi uvicorn streamlit requests httpx pytest
..\.venv\Scripts\python.exe -m service.prepare
```

Каждый раз — три окна:

```
окно 1:  ..\.venv\Scripts\python.exe -m uvicorn service.main:app --port 8000
окно 2:  ..\.venv\Scripts\python.exe -m streamlit run frontend/app.py --server.port 8501
окно 3:  ..\.venv\Scripts\python.exe -m streamlit run dashboard/app.py --server.port 8502
```

Окно 1 готово, когда напишет `Сервис готов` и `Application startup complete` (10–20 с). Адреса: сервис http://localhost:8000/docs, интерфейс http://localhost:8501, панель http://localhost:8502.
